FAQ
Common questions
Is 4K quality really preserved?
+
Yes — the server uses container remuxing only, zero re-encoding. Your 4K HDR file is delivered byte-for-byte at original bitrate.
Why use cookies?
+
Some content (age-restricted, private, or your own uploads) needs your browser session. Add your own cookies.txt in Settings — they're only used for your downloads.
What's the queue for?
+
Multiple downloads run up to 2 at a time. Others queue automatically so the server never chokes on simultaneous large files.
Can I download a whole playlist?
+
Yes! Switch to the Playlist tab, paste the playlist URL, select which videos you want, and queue them all at once.
